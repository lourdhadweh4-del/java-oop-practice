# Java OOP Practice
This repository contains Java programming exercises focused on fundamental object-oriented programming (OOP) concepts.

## Concepts Covered
- Classes and objects
- Object-Oriented Programming (OOP)
- Methods
- Encapsulation
- Inheritance basics
- Problem solving
- Code organization

## Tools Used
- Java
- IntelliJ IDEA

## Purpose
To practice the core principles of object-oriented programming and understand how classes and objects interact in Java.

Object-Oriented Programming is a programming approach that organizes code into objects containing both data and behavior, helping improve code structure and reusability.
